# 🗺️ Business & Sustainability Roadmap

This document outlines the funding and sustainability strategy for **Pifeon**. As a privacy-first, community-driven project licensed under the **GNU GPLv3**, Pifeon rejects intrusive monetization models (such as data selling or ads). Instead, it focuses on infrastructure grants, community support, and ecosystem partnerships.

---

## 📍 Stage 1: Bootstrapping & Zero-Cost Infrastructure (Months 1–6)
*Objective: Build and launch the Minimum Viable Product (MVP) without incurring operational costs.*

- **Sovereign Signaling Infrastructure:** Run the `Pifeon.Server` on **Oracle Cloud Always Free Tier** (providing up to 4 ARM Ampere Cores and 24 GB of RAM) to guarantee 100% uptime for the 6-digit code pairing service without maintenance costs.
- **Product Showcase & Marketing:** Host the product's landing page and documentation on **Cloudflare Pages** or **GitHub Pages**, leveraging global CDN performance with zero bandwidth limits.
- **Developer Domains:** Secure cost-free domain mappings via open-source-friendly registries such as **DigitalPlat FreeDomain**.
- **Distribution Channels:** Publish the desktop application on the **Microsoft Store** (via MSIX) and **Ubuntu Snap Store / Flathub** (via Snapcraft/Flatpak) to automate deployments and user updates using free vendor store networks.

---

## 📍 Stage 2: Community Support & Micro-Donations (Months 6–12)
*Objective: Build an open financial ledger to cover initial scaling and development rewards.*

- **Open Collective & GitHub Sponsors:** Set up transparent financial nodes to accept public contributions from privacy advocates and power users. 
- **Open-Source Crowdfunding Integrations:** Implement tools like **thanks.dev** to automatically receive passive micro-donations directly from the dependency graphs of corporations using the software stack.
- **Feature Bounties:** Allocate community-donated funds to specific GitHub issues, incentivizing external contributors to build highly requested features (e.g., specific CLI automations or advanced GUI plugins).

---

## 📍 Stage 3: Ecosystem Grants & Big Tech Sponsorships (Year 1+)
*Objective: Secure major institutional and corporate grants to turn Pifeon into a premier digital common.*

### 🇪🇺 European & Public Interest Grants
- **NLnet Foundation (NGI Zero):** Apply for Next Generation Internet (NGI) funds backed by the European Commission. These grants reward developers creating encrypted, decentralised digital tools with non-equity funding between €5,000 and €50,000.
- **Sovereign Tech Fund:** Target public infrastructure capital specialized in securing open-source tooling, data privacy, and robust underlying network layers.

### 🌐 Corporate Cloud Sponsorships
- **Microsoft FOSS Fund & Azure Credits:** Leverage the C#/.NET 9 foundation of Pifeon to qualify for Microsoft's developer ecosystem programs. This opens access to recurring Azure cloud credits to sustain massively scaled global signaling nodes.
- **Canonical Ecosystem Recognition:** Request integration into Canonical's official Linux showcases, scaling distribution and leveraging automated build networks across cross-platform Linux architectures (x64, ARM, etc.).

---

## 📍 Stage 4: Long-Term Horizon & Enterprise Extensibility (Future)
*The Open-Core Philosophy: Keep the client 100% free while adding optional enterprise convenience.*

- **Self-Hosted Corporate Node Support:** Provide specialized Docker templates of the orchestration engine for large businesses requiring an internally self-hosted network isolated from public servers.
- **Paid Support & Integration:** Offer premium consulting for large scale operations wanting to embed the Pifeon streaming engine into their continuous integration (CI/CD) pipelines or secure backup structures.
